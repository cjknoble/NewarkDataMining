# Scripts for Investigation of Lead Exposure and its Covarying Factors in Newark, NJ 
These scripts are used for pulling and analyzing the covariation in data from different sources for the city of Newark.
This includes pulling satellite imagery from Google Earth Imagery as well as Google search term results. 
Covariation mining scripts are used to draw out temporal covariation between datasets, applying appropriate linear transformations as needed.
Covariations are used to create a system dynamics simulative model in iSee System's Stella Architect (not included on Github). 
Policy investigation scripts ingest simulative model results when various forms of policy interventions are applied.
